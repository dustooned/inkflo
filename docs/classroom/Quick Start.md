# Inkflo quick start

**The Last Train** is a one-page comic with two panels. The script, layout, ink, and lettering are ready to edit. The exercise takes about 10 minutes.

1. Open [Inkflo](https://dustooned.github.io/inkflo/). Choose **Open starter comic** on the library screen. You can also choose **Import .inkflo** and select **The Last Train.inkflo**.
2. Open **Script**. Read the two beats, then edit one line. Use one line per balloon. Start a speech line with a speaker name, as in **MINA: Hold that door!**. Use **CAPTION:** for a narration box.
3. Open **Layout**. Use **Resize gutters** to move the shared cut. Use **Transform panel → All panels** to resize the whole layout from a corner. Undo to restore the example.
4. Open **Draw**. Select **Brush → G-pen** and add a mark. On a tablet, use two fingers to pan, pinch, and twist. Use **Canvas view → Fit page** to return upright.
5. Open **Caption**. Choose **Review script changes** and apply the line you revised. Use **Find a balloon** to select Mina's balloon, then edit **Words** in the inspector. Drag the body to move it or a tail tip to aim it.
6. Choose **Export → Book file** for an editable Inkflo backup. For another drawing app, choose **Export → Layered PSD**. The PSD contains panel ink and rasterized lettering on separate layers.

To open the supplied PSD in Clip Studio Paint, choose **File → Open** and select **The Last Train.psd**. In Procreate, import the PSD from Files. Toggle the **Lettering** layer and open each numbered panel group to see its **Ink** layer.
